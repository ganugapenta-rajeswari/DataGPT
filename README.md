# DATAGPT AI

AI-powered PDF chatbot using Flask, Groq, LangChain, and FAISS.

## Features
- Upload PDF files
- Ask questions from uploaded PDFs
- RAG-based retrieval
- Fast AI responses using Groq API

## Tech Stack
- Flask
- LangChain
- FAISS
- Groq API
- HTML/CSS/JavaScript
